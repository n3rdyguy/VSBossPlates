# Changelog

All notable changes to VS Boss Plates are listed here.

## [0.1.0] - 2026-08-08

First build. Not released.

### Added
- **Boss health plates.** While a boss is alive, a plate follows it showing a health bar, the
  boss name, and current/max HP. The game says none of this: it draws no boss health UI of any
  kind, and never names the boss you are fighting.
- Config `Enabled`, `ShowName`, `ShowNumbers`, `HideWhenFull`, `VerticalOffset`, `PlateScale`,
  and `DebugVerbose`.
